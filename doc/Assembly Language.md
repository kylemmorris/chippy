I'm not aware of a formal assembly language for CHIP-8. Thus, I am making my own here.

File type: `.c8a`
# Comments
Comments start with a semicolon (`;`) and are ignored by the assembler. Useful for note-taking.
# Opcodes
Each opcode has a 1:1 in CHIP-8 assembly. The table below maps each one. Each assembly instruction follows a four-letter mnemonic, and is case-insensitive. Prefer lowercase.

| CHIP-8 Opcode | Format         | Mnemonic                        | Description                                                                                                                                                                                                                                                                                                                                                                                |
| ------------- | -------------- | ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 0NNN          | `calm 0xNNN`   | Call Machine                    | Call machine code routine.                                                                                                                                                                                                                                                                                                                                                                 |
| 00E0          | `clsc`         | Clear Screen                    | Clear screen.                                                                                                                                                                                                                                                                                                                                                                              |
| 00EE          | `retr`         | Return                          | Return from subroutine.                                                                                                                                                                                                                                                                                                                                                                    |
| 1NNN          | `jump 0xNNN`   | Jump                            | Jump to address.                                                                                                                                                                                                                                                                                                                                                                           |
| 2NNN          | `call 0xNNN`   | Call                            | Call subroutine.                                                                                                                                                                                                                                                                                                                                                                           |
| 3XNN          | `jrec X 0xNN`  | Jump Register Eq Constant       | Skip next instr if VX == NN                                                                                                                                                                                                                                                                                                                                                                |
| 4XNN          | `jrnc X 0xNN`  | Jump Register NotEqual Constant | Skip next instr if VX != NN                                                                                                                                                                                                                                                                                                                                                                |
| 5XY0          | `jrer X Y`     | Jump Register Equal Register    | Skip next instr if VX == VY                                                                                                                                                                                                                                                                                                                                                                |
| 6XNN          | `setc X 0xNN`  | Set to Constant                 | Set VX to NN                                                                                                                                                                                                                                                                                                                                                                               |
| 7XNN          | `addc X 0xNN`  | Add Constant                    | Add NN to VX                                                                                                                                                                                                                                                                                                                                                                               |
| 8XY0          | `setr X Y`     | Set to Register                 | Set VX to value of VY                                                                                                                                                                                                                                                                                                                                                                      |
| 8XY1          | `btor X Y`     | Bitwise OR                      | Set VX to VX or VY                                                                                                                                                                                                                                                                                                                                                                         |
| 8XY2          | `band X Y`     | Bitwise AND                     | Set VX to VX and VY                                                                                                                                                                                                                                                                                                                                                                        |
| 8XY3          | `bxor X Y`     | Bitwise XOR                     | Set VX to VX xor VY                                                                                                                                                                                                                                                                                                                                                                        |
| 8XY4          | `addr X Y`     | Add Register                    | Add VY to VX.                                                                                                                                                                                                                                                                                                                                                                              |
| 8XY5          | `subr X Y`     | Subtract Register               | Subtracts VY from VX.                                                                                                                                                                                                                                                                                                                                                                      |
| 8XY6          | `bshr X`       | Bit Shift Right                 | Shifts VX right by 1.                                                                                                                                                                                                                                                                                                                                                                      |
| 8XY7          | `subr X Y`     | Subtract register.              | Set VX to VY minus VX.                                                                                                                                                                                                                                                                                                                                                                     |
| 8XYE          | `bshl X`       | Bit Shift Left.                 | Shifts VX left by 1.                                                                                                                                                                                                                                                                                                                                                                       |
| 9XY0          | `jrnr X Y`     | Jump Register NotEq Register    | Skip next instr if VX != VY                                                                                                                                                                                                                                                                                                                                                                |
| ANNN          | `seti 0xNNN`   | Set `I`.                        | Set I to address NN.                                                                                                                                                                                                                                                                                                                                                                       |
| BNNN          | `jmpc 0xNNN`   | Jump PC.                        | Jump to address NNN + V0.                                                                                                                                                                                                                                                                                                                                                                  |
| CXNN          | `rand X 0xNN`  | Random.                         | Sets VX to the result of a bitwise and operation on a random number (Typically: 0 to 255) and NN.                                                                                                                                                                                                                                                                                          |
| DXYN          | `draw X Y 0xN` | Draw.                           | Draws a sprite at coordinate (VX, VY) that has a width of 8 pixels and a height of N pixels. Each row of 8 pixels is read as bit-coded starting from memory location I; I value does not change after the execution of this instruction. As described above, VF is set to 1 if any screen pixels are flipped from set to unset when the sprite is drawn, and to 0 if that does not happen. |
| EX9E          | `jker X`       | Jump Key Eq Register.           | Skip if key in VX is pressed.                                                                                                                                                                                                                                                                                                                                                              |
| EXA1          | `jknr X`       | Jump Key NotEq Register.        | Skip if key in VX is not pressed.                                                                                                                                                                                                                                                                                                                                                          |
| FX07          | `tget X`       | Timer get.                      | Set VX to value of delay timer.                                                                                                                                                                                                                                                                                                                                                            |
| FX0A          | `getk X`       | Get Key.                        | Set VX to awaited key press.                                                                                                                                                                                                                                                                                                                                                               |
| FX15          | `tset X`       | Timer set.                      | Sets the delay timer to VX.                                                                                                                                                                                                                                                                                                                                                                |
| FX18          | `sset X`       | Sound (timer) set.              | Sets the sound timer to VX.                                                                                                                                                                                                                                                                                                                                                                |
| FX1E          | `mems X`       | Memory set.                     | Adds VX to I. VF is not effected.                                                                                                                                                                                                                                                                                                                                                          |
| FX29          | `sprt X`       | Sprite.                         | Sets I to the location of the sprite for the character in VX (only consider the lowest nibble). Character 0-F (in hex) are represented by 4x5 font.                                                                                                                                                                                                                                        |
| FX33          | `bcds X`       | BCD Set.                        | Stores the [binary-coded decimal](https://en.wikipedia.org/wiki/Binary-coded_decimal "Binary-coded decimal") representation of VX, with the hundreds digit in memory at location in I, the tens digit at location I+1, and the ones digit at location I+2.                                                                                                                                 |
| FX55          | `dump X`       | Dump (Register).                | Stores from V0 to VX (including VX) in memory, starting at address I. The offset from I is increased by 1 for each value written, but I itself is left unmodified.                                                                                                                                                                                                                         |
| FX65          | `load X`       | Load (Register).                | Fills from V0 to VX (including VX) with values from memory, starting at address I. The offset from I is increased by 1 for each value read, but I itself is left unmodified.                                                                                                                                                                                                               |
# Labels 
Labels start with `label` and continue to the end of the line. See this example:

```
; Example of jumping to a label.
; This is an infinite loop...!
label loop_start
	clsc            ; Clear screen
	setc 0 0x01     ; Set V0 to 1
	jump loop_start ; Jump to the label above
```
